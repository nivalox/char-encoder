How it works
👁️
Invisible Ink
Unicode Variation Selectors (U+FE00–U+E01EF) are zero-width characters that carry byte values 0–255 invisibly.
🔐
AES Encryption
Three cipher modes: GCM (authenticated), CBC (classic), CTR (stream). All use AES-256 with SHA-256 key derivation.
⚡
Base64 + AES
Double obfuscation: message is Base64-encoded first, then AES encrypted. Decoder auto-detects and strips both layers.
🎲
Key Generator
Generate cryptographically secure random keys. A strong key makes brute-force attacks computationally impossible.
