How it works
👁️
Invisible Ink
Uses Unicode Variation Selectors (U+FE00–U+FE0F and U+E0100–U+E01EF) — invisible characters that carry byte values 0–255.
🔐
Any Carrier
Any emoji, letter, word, or phrase can be the host. The visible text is unchanged — only invisible data is appended.
🌊
Spread Mode
Distributes hidden bytes evenly across every character of a phrase, so no single character accumulates a suspicious data block.
